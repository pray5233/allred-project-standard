# 证据等级说明

| 等级 | 含义 | 可作为最终结论 |
| --- | --- | --- |
| guess | 根据经验推测，尚未验证 | 否 |
| static_analysis | 阅读代码、文档、日志、结构后形成判断 | 否，除非任务本身就是只读分析 |
| offline_validation | 用样例、历史数据、模拟环境跑通 | 阶段结论 |
| live_validation | 在真实设备、真实系统、真实流程中验证 | 强结论 |
| product_closure | 可重复、可交付、可回退、有人能接手 | 交付结论 |

提醒：

```text
猜测不是结论；
静态分析不是实机验证；
离线闭合不是产品可用；
打包成功不是现场验证通过。
```
