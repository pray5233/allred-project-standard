# 项目类型问题库

Use this reference when the project type is recognizable and more specific questions would help.

Usually ask through one compact decision card, then draft or proceed. Use numbered options. Make option `1` the recommended default when possible.

## Excel Or Table Automation

Use for exported lists, tracking tables, summaries, and recurring spreadsheet cleanup.

First question:

```text
本轮先处理哪种输入？
1. 一个固定格式 Excel/CSV 文件（推荐）：先跑通最小闭环。
2. 多个同类文件合并。
3. 多个部门不同格式文件。

请回复数字，也可以直接写自定义输入。
```

Current-scope default:

- protect original files
- read one sample file
- generate one cleaned output file
- list rows that cannot be processed

## File Batch Processing

Use for renaming, sorting, converting, moving, archiving, or packaging files.

First question:

```text
本轮对原始文件如何处理？
1. 只读原始文件，输出到新文件夹（推荐）。
2. 允许复制后改名，不改原始文件。
3. 允许直接改原始文件。

请回复数字，也可以直接写自定义边界。
```

Current-scope default:

- dry-run preview first
- output a change log
- require confirmation before destructive changes

## Internal Query Or Search Tool

Use for document directory, knowledge lookup, customer or project record search.

First question:

```text
本轮先支持哪种查询？
1. 按关键词搜索标题、文件名或摘要（推荐）。
2. 按分类筛选。
3. 支持自然语言问答。

请回复数字，也可以直接写自定义查询方式。
```

Current-scope default:

- index a small folder or sample dataset
- show source path
- avoid claiming answers without source evidence

## Online Market Intelligence Or Public Information Monitoring

Use for automatic search, public market dynamics, competitor updates, product price/news tracking, exhibition information, source collection, and scheduled report generation.

Read `references/公开信息监测项目.md`. That reference owns route approval boundaries, minimum validation definition, first-round scope, source feasibility, summary provenance, credential handling, classification, and acceptance.

Do not select sources, topics, product features, framework, or delivery from this generic question bank.

## Small App Or Desktop Tool

Use for a tool with a UI, buttons, import/export, or repeated operator use.

First question:

```text
本轮界面重点是什么？
1. 能导入、处理、导出并显示结果（推荐）。
2. 先做完整界面原型。
3. 先做命令行版本，界面后续再加。

请回复数字，也可以直接写自定义界面要求。
```

Current-scope default:

- one main screen
- clear import/output controls
- visible processing result
- simple error message

## Test Data, Logs, Or Technical Archive

Use for test files, logs, measurement data, technical materials, and archive directories.

First question:

```text
本轮归档依据是什么？
1. 按项目/日期/设备/测试类型生成目录（推荐）。
2. 按文件名规则自动分类。
3. 按人工填写的清单分类。

请回复数字，也可以直接写自定义规则。
```

Current-scope default:

- keep original data unchanged
- generate directory and index
- record unknown or unmatched files

## Knowledge Directory

Use for现场问题资料、定制产品资料、制度文件、经验沉淀.

First question:

```text
本轮知识库先解决什么问题？
1. 先整理目录和标签，能快速找到资料（推荐）。
2. 先做全文搜索。
3. 先做问答和摘要。

请回复数字，也可以直接写自定义目标。
```

Current-scope default:

- organize source path
- create category and tag fields
- keep source document link
- avoid rewriting source documents

## Multi-Department Weekly Report Or Progress Tool

Use for multiple exported lists, project status, follow-up records, weekly summaries.

First question:

```text
本轮先汇总哪些数据？
1. 一个部门的一类清单生成周报（推荐）。
2. 多个部门同格式清单生成周报。
3. 多个部门不同格式清单生成项目进度表。

请回复数字，也可以直接写自定义数据范围。
```

Current-scope default:

- start with one department or one list type
- define status rules
- output a draft weekly report
- mark uncertain rows for manual review

## Customer Equipment Or Problem Follow-Up

Use for customer equipment lists, issue feedback, delivery follow-up, and service tracking.

First question:

```text
本轮跟踪表最需要盯住什么？
1. 未关闭问题和负责人（推荐）。
2. 客户设备清单和状态。
3. 发货、反馈、处理记录的完整链路。

请回复数字，也可以直接写自定义跟踪重点。
```

Current-scope default:

- identify open items
- assign status and owner fields
- output follow-up table
- preserve original records
