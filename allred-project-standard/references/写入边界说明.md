# 写入边界说明

默认规则：

```text
先只读观察；
再明确允许写什么；
关键动作必须人工确认。
```

| 对象 | 推荐规则 |
| --- | --- |
| 原始资料 | 只读，结果另存 |
| 真实设备 | 默认只读观察；即使范围或计划已批准，命令、采集、补偿/校准写入仍需动作级授权 |
| 业务系统 | 不自动提交、审批、付款、删除 |
| 同一源码文件 | 同一时间只允许一个 owner 修改 |
| 同一 tracker | 只能由总控 owner 汇总 |
| 同一最终结论 | 只能有一个事实源 |
| Git 分支 | 专项开发用分支或 worktree，总控负责合并 |

禁止在计划未确认前执行：

- 删除、覆盖、移动原始资料
- 写入真实设备
- 自动付款、审批、提交业务系统
- 自动提交 Git
- 安装未知依赖
- 修改共享 tracker 或最终结论
