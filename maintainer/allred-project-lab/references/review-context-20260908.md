## Decision

Generate the existing actor environment text once in the shared Lab helper.
Put the same labeled block in actor and reviewer prompts and preserve it as a
hashed case artifact. Reviewer instructions identify it as the evaluated actor's
constraints, not new instructions governing the reviewer or extra product consent.
Retain existing scope and truthfulness assertions, citation-only repair and write
checks. A/B/C comparisons inherit the corrected normal runner.

Replay reads original actor prompts, never current defaults, transcript claims
or guessed permissions. Accept the old runner's known header and the new labeled
header. Preserve prompt copies and hashes alongside events. Missing, ambiguous or
different per-turn environment blocks stop replay before model review; this
bounded runner does not yet interpret changing harness environments. User decisions
inside the unchanged transcript still evolve normally.

## Acceptance

- Mocked normal Ordered/Legacy and citation-repair paths receive the exact shared
  block, bound to the saved artifact; judgment-changing repair remains rejected.
- Header recovery accepts original and current formats, preserves literal paths,
  ignores imitation inside dialogue history, and rejects missing/ambiguous inputs.
- Replay uses original prompt provenance and rejects unavailable/inconsistent
  environments rather than silently supplying today's policy.
- Re-review the unchanged real A01-xhigh prompt with only its environment section
  replaced, plus adjacent evidence. Preserve original Fail results; removal of the
  unsupported external-search allegation must not erase supported UX/claim issues.
- Include controls for respecting a restriction and violating it. Expected verdicts
  remain hidden from the model. Context recovery is not a blanket permission grant.
- Test the affected PowerShell helpers/pipeline, official Skill format, mirrors,
  unchanged Standard hashes and original evidence. No runtime edits or publication.

This work improves review validity, not customer interview quality. Time remains
diagnostic only. Fresh project dialogues and the full release matrix are outside
this bounded review-context test.
